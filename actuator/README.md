# Actuator

The Actuator is a component responsible for applying resource recommendations generated by the optimization system. It reads recommendations from a CSV file and applies them to the Kubernetes cluster through Karmada, but it was developed generically to support other orchestrators in the future.

## Prerequisites

- Go 1.19 or higher
- Access to a Kubernetes cluster with Karmada configured
- [simulator-experiments](https://github.com/cloud-ai-ufcg/simulator-experiments) repository configured

## Configuration

1. Clone this repository:
```bash
git clone https://github.com/cloud-ai-ufcg/ai-engine.git
cd ai-engine/actuator
```

2. Install dependencies:
```bash
go mod download
```

3. Make sure the simulator-experiments repository is configured and accessible, as it is responsible for creating the necessary jobs and deploys for the system to function.
Example of `csv` for the creation script:
```csv
timestamp,id,kind,job_duration,action,replicas,cpu,memory,label
0,1000,deployment,,create,1,16,0.08481867833199597,public
0,10000,deployment,,create,2,4,0.042409339165997983,private
0,10001,deployment,,create,1,2,0.03,NA
0,10002,deployment,,create,2,3,0.04,NA
0,1-1,job,1000,create,12,1,0.00275412212357311,NA
0,2-2,job,NA,create,12,1,0.00275412212357311,NA
0,6-6,job,1000,create,12,1,0.00275412212357311,private
0,7-7,job,1000,create,12,1,0.00275412212357311,public
0,8-8,job,1000,create,12,1,0.00275412212357311,public
```

## Recommendations File Structure

The `recommendations.csv` file should follow this format:
```csv
workload_id,label,kind
1000,0,deployment
10000,1,deployment
10001,1,deployment
10002,0,deployment
1-1,1,job
2-2,0,job
6-6,1,job
7-7,0,job
8-8,0,job
```

## Execution

1. First, run the necessary scripts from the simulator-experiments repository to create the jobs and deploys:

2. Return to the actuator directory and run:
```bash
cd ../actuator
go run main.go
```

## How it Works

The Actuator:
1. Reads recommendations from the `recommendations.csv` file
2. Connects to the Kubernetes cluster through Karmada
3. Applies resource recommendations for each specified workload
